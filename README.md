# 二次元壁纸

**本仓库只存放图片和视频，作为另一个仓库 [ecy-wallpaper-api](https://github.com/lb94wpz/ecy-wallpaper-api) 的图床使用。**

通过链接：`https://cdn.jsdelivr.net/gh/lb94wpz/ecy-wallpaper@master/<目录>/<文件名>` 直接访问图片。

## 上传新的壁纸

1. 在本仓库根目录下新建一级目录，把图片 / 视频放进去；
2. 在根目录 `folders.json` 里补一行对该目录的描述。
